## Методы API

### 1. Регистрация пользователя
* **Метод:** `POST`
* **Путь:** `/register`
* **Параметры:** `username` (строка)
* **Описание:** Регистрация нового пользователя в системе.

### 2. Получение текущей погоды
* **Метод:** `GET`
* **Путь:** `/current_weather`
* **Параметры:** `latitude` (float), `longitude` (float)
* **Описание:** Получение информации о погоде по широте и долготе.
### 3. Добавление города в список отслеживаемых
* **Метод:** `POST`
* **Путь:** `/add_city`
* **Параметры:** `city_name` (строка), `latitude` (float), `longitude` (float), `user_id` (int)
* **Описание:** Добавление нового города в список отслеживаемых пользователем.

### 4. Получение списка отслеживаемых городов
* **Метод:** `GET`
* **Путь:** `/tracked_cities`
* **Параметры:** `user_id` (int)
* **Описание:** Получение списка городов, отслеживаемых пользователем.

### 5. Получение прогноза погоды
* **Метод:** `GET`
* **Путь:** `/weather_forecast`
* **Параметры:** `user_id` (int), `city_name` (строка), `time` (строка), `parameters` (набор параметров)
* **Описание:** Получение прогноза погоды для указанного города и времени.
